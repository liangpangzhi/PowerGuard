# PowerGuard 断电自动关机守护

> 笔记本检测到电源从交流供电切换为电池供电后，倒数若干秒自动关机的 Windows 小工具。

单文件 exe，无需安装 Python；托盘常驻，图形界面设置；**默认模拟模式**，确认后才真正关机。

## 功能

| 能力 | 说明 |
| --- | --- |
| 电源跳变检测 | 每 1 秒轮询，仅在「交流 → 电池」跳变时触发；插回电源自动复位 |
| 倒计时关机 | 触发延迟 + 可配置倒计时（1–3600 秒），倒计时窗口可取消（按钮 / Esc） |
| 恢复供电自动取消 | 倒计时期间每 0.2 秒检测，恢复交流供电立即中止关机 |
| 模拟模式（DRY-RUN） | 默认开启，只提示不关机；切换真实模式需两次确认 |
| 图形设置窗口 | 双击托盘图标打开，可改倒计时、触发延迟、模拟模式、开机自启、静默启动 |
| 开机自启 | 写入 HKCU Run 并回读校验，清理 StartupApproved 禁用标记，自启时以 `--silent` 完全静默 |
| 单实例 | 程序运行中再次双击 exe，会唤起已运行实例的设置窗口 |

## 使用

1. 下载 [Releases](../../releases) 中的 `PowerGuard.exe`，放到固定目录（如 `C:\Tools\PowerGuard\`）。
2. 双击启动，托盘出现图标；右键菜单可模拟测试、暂停监控、打开设置。
3. 确认倒计时行为正常后，在设置里取消「DRY-RUN 模拟模式」并用新位置重新勾选开机自启。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--silent` | 静默启动，只驻留托盘（开机自启使用） |
| `--selftest` | 运行内置自检 |
| `--uitest` | 界面与交互自检 |
| `--demo` | 演示倒计时流程（不关机） |

## 安全

- 默认 DRY-RUN，真实关机会经过两次确认。
- 真实关机仅调用系统 `shutdown.exe /s /t 0`，从不重启、不删除数据。
- 设置环境变量 `POWERGUARD_SAFE=1` 可强制锁定为模拟模式。

## 构建

